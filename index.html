国内调用代码

bash · curlready
curl https://4zapi.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-4","messages":[{"role":"user","content":"ping"}]}'
python · openaiready
from openai import OpenAI
client = OpenAI(api_key="YOUR_API_KEY", base_url="https://4zapi.com/v1")
print(client.chat.completions.create(
    model="claude-sonnet-4",
    messages=[{"role":"user","content":"ping"}],
).choices[0].message.content)
node · openaiready
import OpenAI from "openai";
const client = new OpenAI({ apiKey: process.env.API_KEY, baseURL: "https://4zapi.com/v1" });
const r = await client.chat.completions.create({
  model: "claude-sonnet-4",
  messages: [{ role: "user", content: "ping" }],
});
console.log(r.choices[0].message.content);
